# Системный helper для Debian и Ubuntu

Рецепт собирает `yonik-helper` из двух готовых release ELF. Для запуска нужны
systemd в PID 1 и единая иерархия cgroup v2.
Используйте `yonik-helper` и `yonik-worker` из того же коммита, что и рецепт,
с glibc целевой системы. Архитектуру и минимальную версию glibc скрипт определяет
по ELF.
Сборка требует Bash, GNU coreutils, binutils и dpkg. Пример из корня репозитория:

```sh
mkdir -p ./dist
SOURCE_DATE_EPOCH="$(git log -1 --format=%ct)" bash packaging/debian/build.sh \
    "$CARGO_TARGET_DIR/release" 0.1.0-1 ./dist
```

Пакет устанавливает системные службы, политику polkit и конфигурацию D-Bus.
Зависимости при установке готового архива разрешает `apt install ./пакет.deb`.
Для TUN также нужны desktop-клиент, `/dev/net/tun` и
[доверенный реестр движков](../arch/README.md#archcachyos-x86_64). Реестр
и бинарники Xray и sing-box поставляются отдельно.
Рецепт предназначен для локальной сборки и проверки. Для публикации свяжите
точные ELF с соответствующими исходниками и уведомлениями зависимостей по
[правилам проекта](../licenses/SOURCE-OBLIGATIONS.md).

Установка создаёт системного пользователя `yonik-worker` и обновляет
конфигурацию systemd. Helper активируется по запросу через D-Bus. Перед
обновлением или удалением завершите сессию и разблокируйте сеть в приложении.
Перед заменой файлов пакет закрывает приём новых Apply и активацию helper,
проверяет состояние сессии и останавливает службы. После `dpkg --unpack`
активация возобновляется при `dpkg --configure yonik-helper`.
Карантин ранее выданных Fake-IP истекает по таймеру ядра. Конфигурацию DNS
и пользовательские данные пакет не меняет.

На Debian 13 и Ubuntu 24.04 amd64 проверены установка и активация через D-Bus,
обновление и откат версии без активной сессии, отказ обновления и удаления
при активном TUN с Xray и sing-box. После Stop и Unlock удаление завершило
helper, а карантин IPv4 и IPv6 истёк по таймеру ядра. Содержимое и метаданные
`/etc/resolv.conf` сохранились. Для `arm64` нужна отдельная проверка установки
и сетевого цикла.
